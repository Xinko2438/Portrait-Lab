## 未纳入默认公开测试集

原工程中部分集成测试读取私人模板目录，另一些需要额外浏览器测试环境。这些用例未随默认公开快照导出。公开测试通过不能代替它们，也不能证明某个远端模型的成片质量。

为适配公开快照，仅调整了配置保存模块的工作区依赖、包名称及测试并发，并将几处早于当前界面的旧断言对齐到实际图标、可访问性属性和客户选择位置。未修改本机原工作台或其业务数据。

当前支持环境为 Windows；真实 API 需要自行配置，网页渠道依赖使用者自己的浏览器授权和登录。配置保存限制在本项目数据根的 `data/private-config/`，服务默认只监听回环地址。课程教学附件未分发，内置教程入口为本公开版本的简明操作说明。
